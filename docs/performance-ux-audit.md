# Mind Verse — хурд ба UI/UX-ийн засвар

Шалгасан сайт: https://mind-verse-six.vercel.app/
Огноо: 2026-09-15 (Улаанбаатар)

## Гол дүгнэлт

Эхний ачааллын хамгийн том саад нь профайлын зургуудыг base64 хэлбэрээр JSON дотор давтан илгээж байсан явдал. Нээгээгүй постын сэтгэгдлийг урьдчилан татаж, зарим алдааг автоматаар дахин дахин давтах болон бүх дүрсний фонтыг татах нь ачааллыг нэмэгдүүлж байв.

## Хэмжсэн өөрчлөлт

| Хэмжилт | Өмнөх live сайт | Зассан production build |
|---|---:|---:|
| 10 постын JSON | 1,703,812 B | 5,717 B |
| 81 сурагчийн JSON | 2,858,811 B | 16,184 B |
| Material Symbols WOFF2 | 1,132,416 B | 10,336 B |
| Эхний 10 постын нээгээгүй сэтгэгдлийн нэмэлт хүсэлт | 10 | 0 |
| Нүүр хуудасны DOM элементийн тоо | 989 | 691 |

JSON хэмжээ 99%-иас илүү буурсан нь бүх сайтын ачааллын хугацаа 99% багассан гэсэн үг биш. Аватарууд тусдаа, хэрэгтэй үедээ татагдана. Эх зураг, нийтлэл, сурагчдын өгөгдөл өөрчлөгдөөгүй.

Локал production HTTP шалгалтын нэг удаагийн хэмжилт: пост 1,171 ms, хуваалцсан нэг пост 391 ms, дараагийн хуудас 373 ms, хоосон хайлт 192 ms, сурагчид 200 ms, хичээл 1,070 ms, уралдаан 392 ms. Өмнөх live пост/сурагчийн хүсэлт 4,048/4,897 ms байсан. Орчин, байршил, cache өөр тул үүнийг шууд харьцуулсан хурдны баталгаа гэж үзэхгүй.

## Хийсэн засвар

- Үндсэн DB жагсаалтаас том avatar_url баганыг хасаж, 96px WebP аватар тусдаа татдаг болгосон. Гаднын аватарын холбоос болон эх зургууд хадгалагдсан.
- Зэрэг ирсэн унших хүсэлтүүдийг нэгтгэсэн; хугацаа дууссан болон шинэчлэгдсэн cache-ийг хуучин хариу дахин дүүргэх алдааг зассан. HTTP status, header хадгалагдана.
- Пост/хичээлийн хэрэглэгчээс хамаарах хариуг нийтийн HTTP cache-д хадгалахгүй болгосон.
- Хайлт 300 ms завсарласны дараа ажиллана; хуучин хүсэлтийг цуцалж, шүүлтүүр болон дараагийн хуудсын зөрчилдөөнөөс хамгаалсан.
- Сэтгэгдэл зөвхөн нээхэд ачаална. Алдааны давталтыг зогсоож, дахин оролдох товч нэмсэн. Хаахад бичиж буй ноорог хадгалагдана.
- Зургийг бүтнээр нь харуулах тогтмол талбай, responsive Cloudinary хувилбар, эхний зурагт priority, бусдад lazy loading нэмсэн.
- Хуваалцсан `/?post=...` холбоос тухайн постыг тусад нь харуулна.
- Нүүр хуудсанд утга бүхий гарчиг, харагдах хайлт, нийтлэх/нэвтрэх үйлдэл, хоосон үр дүн, skeleton болон тайлбартай retry төлөв нэмсэн.
- Бодит биш хугацааны мэдээлэл болон тогтмол “3 уралдаан” badge-ийг хассан. Ажилладаггүй bookmark товчийг хассан.
- Монгол кириллд тохирох Noto Sans, уншихад эвтэй текстийн хэмжээ, 44px touch target, focus outline, reduced-motion нэмсэн.
- Гар утасны цэсийг далд үед inert болгож, Tab/Escape/focus буцах үйлдэл болон нэвтрэх холбоос нэмсэн. Desktop навигац keyboard-аар ажиллана.
- Туслах, сэтгэгдэл, том зураг зэрэг UI-г шаардлагатай үед ачаална. Туслахын хариу хүлээлт хязгаартай.
- Захиалагчийн сорилт хуудсыг өөрөө гүйлгэдэг байсныг засаж, алдаанд ноорог хадгална.
- Next.js 16.3.3, sharp 0.35.4 болон шаардлагатай засварлагдсан dependency хувилбаруудыг суулгасан. `npm audit`-ийн тухайн үеийн үр дүн: 0 vulnerability.
- Нэмэлт AI мэдээний API түлхүүр байхгүй үед бүх сайт build хийхгүй байсан алдааг зассан; тухайн үйлдэл тохиргооны 503 хариу өгнө. Мэдээ шинэчлэх POST нь багшийн session шаарддаг болсон.

- `git diff --check` — амжилттай.
- Браузер: 1280px/390px, хөндлөн overflow байхгүй; хайлт/цэвэрлэх; сэтгэгдэл нээх; lightbox/Escape/focus буцах; mobile цэс/Escape/inert background; туслах нээх.
- Эхний ачаалалд 10 article, 0 сэтгэгдлийн textarea, 0 эвдэрсэн зураг, браузерын error log хоосон байсан.

## Шалгалтын хязгаар

Нэвтэрсэн хэрэглэгчийн бодит нийтлэл үүсгэх, файл байршуулах, үнэлгээ/реакц илгээх, AI төлбөртэй хүсэлтүүдийг production өгөгдөлд туршиж өөрчлөлт хийгээгүй. Нийтийн унших урсгалууд болон cache/аватар/visibility-ийн логикийг шалгасан. Бүх сүлжээ, төхөөрөмж дээр огт гацахгүй гэсэн баталгаа өгөх боломжгүй.

Өмнөх schema-д `posts.visibility` багана байхгүй нь илэрсэн. Энэ ажлын үндсэн нүүр хуудас PUBLIC нийтлэл ашигладаг; PRIVATE нийтлэл хадгалах бүрэн дэмжлэг нь тусдаа schema өөрчлөлт шаардлагатай. Энэ засварт DB schema өөрчлөөгүй.
