# Mind Verse — компьютер, laptop-ийн дэлгэцийн шинэчлэл

Огноо: 2026-09-15. Өмнөх UI/UX ба хурдны засвар дээр хийсэн дэлгэцийн зохиомжийн нэмэлт ажил.

## Хийсэн өөрчлөлт

- **Ерөнхий бүтэц:** 1024–1535px дэлгэцэд 232px, 1536px-ээс дээш 256px тогтвортой цэс; агуулга 1440px хүртэл хязгаартай. Хуудасны захын зай дэлгэцтэй хамт 28–40px болж өөрчлөгдөнө. Цэсийг утгаар нь бүлэглэж, идэвхтэй хуудсыг тайван өнгө ба зүүн шугамаар ялгав. Тоглоомын дэд цэс хулгана холдох үед хаагдахгүй. Хуудас солиход агуулгын эхэнд очно.
- **Нүүр:** desktop дээр онцлох сурагчид тусдаа хажуугийн баганад, хайлт ба бүтээлүүд үндсэн баганад. Хайлтын том наалдсан хэсэг агуулгыг дарахгүй. Картын бичвэр 75 тэмдэгтийн орчим унших өргөнтэй, зураг дээд өндрийн хязгаартай; үнэлгээ, сэтгэгдлийн үйлдлүүд өргөн дэлгэцэд нэг мөрөнд.
- **Хичээл:** жагсаалт 2–3 баганатай; дэлгэрэнгүй хуудас сорил/ажил ба явц/материалын баганатай. Асуултын сонголт, алхам, үр дүн болон багшийн үнэлгээний хэсгийн зай, бичвэр, товчийг жигдлэв.
- **Уралдаан:** тайлбар ба хугацаа/оролцогч/XP мэдээллийг тусад нь байрлуулсан. Жагсаалт, галерейн картын хэмжээ, доод үйлдлүүд ижил түвшинд байрлана.
- **Профайл:** танилцуулга ба бодит үзүүлэлтүүд тусдаа хэсэгтэй; бүтээлүүд дэлгэцээс хамаарч 2/3/4 баганад. Мэдэгдлийн унших өргөн хязгаартай.
- **Чансаа:** нэр, анги, түвшин/цол, XP баганууд ялгарахуйц; laptop дээр шүүлтүүрүүд нэг мөрөнд. Газрын зургийн бүсүүдийн жагсаалт хажууд харагдана.
- **Тоглоом, хүрд:** laptop-оос хоёр баганатай, зургийн өндөр хязгаартай галерей, хүрд ба сонголтын жагсаалтыг зэрэг харах зохиомжтой.
- **Удирдлага, нэвтрэх:** өргөн дэлгэцэд формын талбаруудыг тохирсон баганад, уншихад зохистой өргөнөөр байрлуулсан. Нэвтрэх хуудасны хоёр тал тэнцвэртэй, тайлбар ба үйлдлүүд нэг харагдацад багтана.
- **Цонх, файл сонгох:** header/footer харагдах хэвээр, урт агуулга дотроо гүйнэ. Файл сонгох товчнууд Монгол бичвэр, гарын фокустай. Туслахын desktop цонх илүү өргөн. Ачаалж буй бүртгэлд буруу guest товч харуулахын оронд цэсийн footer түр ачаалалтын төлөвтэй.

Хуудас бүрийн харагдацыг зурагтайгаар нягталсан. Чансааны хүснэгт/газрын зураг, профайл засах цонх, файл сонгох keyboard focus, Escape болон цонхны footer-ийн багтаамжийг тусад нь шалгав. Туршилтын багш/сурагчийн харагдац нь зөвхөн локал fixture өгөгдөлтэй; бодит хэрэглэгчийн мэдээлэлд туршилтын өөрчлөлт хийгээгүй.

`npm test`: **82/82** амжилттай. Үзэгдэх устгах товч шинэ нэртэй болсон тул тестийг утгатай `aria-label`-аар олохоор шинэчилж, хуучин хүсэлт шинэ үр дүнг дарахгүй гэсэн шалгалтыг хэвээр хадгалсан. TypeScript, production build, `git diff --check`, fixture-ийн тусгаарлалтыг шалгах команд амжилттай.

Энэ нь дээрх хэмжээнүүдийн браузерын шалгалт; бүх төхөөрөмж, бүх browser zoom, бүх хэрэглэгчийн урт бичвэрийг бүрэн хамарсан баталгаа биш. Өмнөх тайлангийн өгөгдлийн сан, имэйлтэй холбоотой хязгаарлалтууд өөрчлөгдөөгүй.
