# Mind Verse — бүх хуудасны UI/UX шалгалт

Огноо: 2026-09-15, Улаанбаатар. Энэ тайлан нь **11 төрлийн хуудсыг хамарсан UI/UX, хурд, алдааны засварын** тухай. [Өмнөх хурдны аудит](performance-ux-audit.md)-ын production байршуулалт нь энэ шинэ багцыг байршуулсан гэсэн үг биш.

## Хуудас бүрийн өөрчлөлт

| Хуудас | Хийсэн сайжруулалт |
|---|---|
| Нүүр `/` | Уншихад эвтэй бүтээлийн карт, харагдах хайлт, хоосон үр дүн, ачаалал/дахин оролдох төлөв; хуучин хайлтын хариу шинэ үр дүнг дарахгүй. Таслал, хаалт, хашилттай хайлт серверийн алдаа үүсгэхгүй. Сэтгэгдэл нээхэд ачаална. |
| Нэвтрэх `/login` | Монгол тайлбар, талбарын нэр, нууц үг харах, имэйл санах; сэргээх кодын хүлээлт, алдаанд ноорог хадгалах. Сурагч бүртгүүлэх боломжтой; багш одоо байгаа бүртгэлээрээ нэвтэрнэ. |
| Профайл `/profile` | Танилцуулга ба бүтээлүүд зэрэг ачаална. Засах цонх, мэдэгдлийн шүүлтүүр, утсан дээр харагдах үйлдлүүд; бүтээлээ 12-оор нэмж харна. Пост засахад ID, зураг, сэтгэгдэл, үнэлгээг хадгална. |
| Хичээлүүд `/lessons` | Хайлт, нэг хэвийн карт, нэртэй талбарууд, файл байршуулалтын төлөв, үүсгэх/засах/устгах цонх. Хоцорсон жагсаалтын хариу баталгаажсан өөрчлөлтийг дарахгүй. |
| Хичээл `/lessons/[id]` | Асуултын алхам, гарын фокус, бодит үр дүн, файл илгээх ба багшийн үнэлгээний төлөв. Сорил дахин өгөхөд өмнөх даалгаврын хавсралт/үнэлгээг арилгахгүй, ижил XP-г давтан нэмэхгүй. |
| Уралдаанууд `/contests` | Хайлт, төлөвөөр шүүх, эхлэх/дуусах хугацаа, шагналын ойлгомжтой мэдээлэл; засах/устгах цонх, давхар хүсэлтийн хамгаалалт. |
| Уралдаан `/contests/[id]` | Бүтээл байршуулж урьдчилан харах, илгээлт/саналын алдаа ба хүлээлт. Өөр уралдаан нээхэд өмнөх зураг, тайлбарын ноорог шилжихгүй. |
| Шилдэг сурагчид `/leaderboard` | Уншигдахуйц эрэмбэ, хайлт/анги, өөрийн байр, алдаа/хоосон төлөв. Хүнд зураглалыг шаардлагатай үед ачаална. |
| Азын хүрд `/spinner` | Сонголт ачаалагдсаны дараа эргүүлэх, давхар даралтыг хаах, эргэлтийн турш сонголтыг тогтвортой хадгалах, үр дүн хуулах, хөдөлгөөн багасгах тохиргоо. |
| Санал хураалт `/game` | Бүтээл, санал, үр дүнг тодорхой харуулах; багшийн эхлүүлэх/дуусгах/шинэчлэх үйлдэлд батлах цонх. Далд tab-д хүсэлт багасгаж, хуучин уншилт шинэ саналыг дарахгүй. |
| Удирдлага `/admin` | Сурагч/анги хайх, XP өөрчлөлтийн хамрах хүрээ ба дүнг урьдчилан харах; устгах, нийт XP тэглэх, нууц үг шинэчлэх тусдаа цонх. Багшийн эрх болон давхар хүсэлтийг шалгана. |

## Нийтлэг загвар ба хурд

- Монгол кириллтэй Noto Sans, нэг загварын гарчиг/талбар/товч, унших зай, гарын фокус, хүрэхэд том товч, хөдөлгөөн багасгах дэмжлэг нэмсэн.
- Гар утасны цэс болон цонхнууд Tab/Escape, фокус буцаах, арын агуулгыг идэвхгүй болгох үйлдэлтэй. Алдаа, ачаалал, олдсонгүй хуудсууд нэмсэн.
- Аватарыг том base64 JSON-оос салгаж, жижиг WebP хэлбэрээр ачаална. Зураг хэрэгтэй үед татагдаж, Cloudinary хэмжээ нь харагдах талбайтай таарна; профайлын grid тусдаа `sizes` утгатай.
- Давхардсан GET-ийг нэгтгэж, cache-ийн хэмжээ/хугацааг хязгаарласан. Хоцорсон хариу, салсан хуудас, давхар даралт, удаан хүсэлтэд хамгаалалт нэмсэн.
- Material Symbols зөвхөн ашигласан дүрсүүдийг татна. Өмнөх аудитад font 1,132,416 B → 10,336 B болсон; энэ нь бүх хуудасны хурд ижил хувиар өссөн гэсэн хэмжилт биш.
- Next.js 16.3.3, sharp 0.35.4 болон холбогдох засварлагдсан dependency хувилбаруудыг ашиглаж байна. DB schema өөрчлөөгүй.

## Аюулгүй ажиллагааны өөрчлөлт

Session-ийг серверийн нууц түлхүүрээр гарын үсэг зурж, хугацааг шалгадаг болгосон. **Шинэ хувилбарт шилжихэд хэрэглэгч дахин нэг удаа нэвтрэх шаардлагатай.** `NC_SESSION_SECRET` ашиглавал серверт хадгалах тогтвортой, 32-оос доошгүй тэмдэгттэй санамсаргүй утга байна. Одоогийн тохиргоонд тусдаа түлхүүр байхгүй үед зөвхөн серверийн хүчтэй хувийн нууцаас зориулалт тус бүрийн түлхүүрийг HKDF-ээр гаргана; нийтэд мэдэгдсэн fallback ашиглахгүй. Нууц үг сэргээх кодын баталгаажуулалт, хугацаа, дахин ашиглалтыг шалгана; production-д имэйл тохируулаагүй бол код илгээсэн мэт амжилт үзүүлэхгүй.

**Кодод суулгасан Gmail app password-ийг хассан. Эзэмшигч Google данснаасаа хуучин app password-ийг цуцалж, шинээр үүсгэн серверийн нууц тохиргоонд оруулах шаардлагатай.** Кодоос устгах нь хуучин түлхүүрийг Google дээр хүчингүй болгодоггүй. Шинэ утгыг репозитор, тайлан, чатад бичихгүй; `GMAIL_USER`/`GMAIL_APP_PASSWORD` эсвэл SMTP тохиргоогоор өгнө.
